# Critical Literary Text Analyst – LLM Skill

## Project Overview

This project develops a Markdown-based skill that guides Large Language Models (LLMs) in critically analysing Hindi literary texts.

It focuses on ecological imagery, cultural elements, symbolism, and human–nature relationships, using selected passages from *Kamayani* by Jaishankar Prasad as its primary literary context.

## Objectives

- Identify ecological elements in Hindi poetry.
- Analyse cultural and philosophical references.
- Interpret metaphors, imagery, and symbolism.
- Examine human–nature relationships.
- Encourage evidence-based literary interpretation.

## Methodology

The skill follows a structured close-reading approach:

1. Read the supplied literary passage.
2. Identify ecological and cultural references.
3. Examine imagery, metaphors, and symbols.
4. Interpret human–nature relationships.
5. Support interpretations with textual evidence.
6. Acknowledge uncertainty and limitations.

## Repository Structure

- `SKILL.md` – Main instructions for the LLM.
- `examples/sample_prompts.md` – Example prompts for testing the skill.

## Tools and Technologies

- Markdown
- GitHub
- Large Language Models (LLMs)
- Hindi literary texts

## Research Connection

This project connects Digital Humanities with Environmental Humanities by exploring how LLM-based tools can support the interpretation of ecological and cultural meanings in Hindi literature.

## Scope and Limitations

This skill provides structured guidance for literary analysis; it is not a trained AI model and does not guarantee definitive interpretations. Its results depend on the quality, completeness, and context of the supplied text.

## Future Scope

The skill can be extended to other Hindi poems, literary traditions, and comparative ecological readings.
